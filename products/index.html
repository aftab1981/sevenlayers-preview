Custom software

Systems built for the people who use them.

Not every problem is a website. We also build the software businesses run on — dashboards, inventories, reporting tools and operational systems — designed around how a team actually works rather than how a generic product assumes they do. The two below are shipped and in daily use.

Shipped product · Infrastructure · Data centre

Unified iDRAC Management

One console for an entire iDRAC estate, instead of one browser tab per server.

  • Every iDRAC host in one console, across multiple sites and environments
  • Fleet health scoring that weights status, firmware drift and drive telemetry
  • Full hardware inventory: CPU, memory, disks, RAID, NICs, PSUs, fans, transceivers
  • Faults, wear and BIOS drift surfaced automatically, ranked by severity

Cyber Security · Microsoft 365

Teams Link Monitor

A security dashboard for Microsoft Teams. It reads every link shared in chats and channels, checks each one against two independent threat-intelligence feeds, flags phishing language in the message text itself, and surfaces when the same malicious link is spreading across several people. It grew from a link scanner into a small SOC platform: case triage, audit logging, SIEM export and campaign detection — with three AI features that run entirely on a local model, so no message content ever leaves the machine.

  • Dual-engine URL reputation — VirusTotal and URLhaus, cross-checked against each other
  • Campaign detection: the same bad link shared by several people surfaces as one incident
  • Phishing-language detection on message text, so a message with no link at all still gets caught
  • Case management — triage status, assignment and a running analyst-note log per URL
  • Three AI features running on a local model via Ollama; no cloud LLM API anywhere in the product
  • CEF export for SIEM ingestion, plus CSV, Excel and a NotebookLM-ready brief

What we build

If your team does it by hand, it can probably be built.

The work below starts the same way every time: someone describes a job that eats hours every week, and we work out whether software would genuinely be cheaper than continuing to do it manually. Sometimes the honest answer is no.

Operational dashboards

One view of something currently scattered across exports, spreadsheets and separate admin panels — with the detail a specialist needs one click below the summary a manager needs.

Inventory & asset systems

Knowing what you own, where it is, what condition it is in and when it needs replacing — assembled from the data your equipment already produces rather than maintained by hand.

Reporting & compliance tooling

The report that currently takes someone two days a month, produced on demand and in a format an auditor or a finance system will accept.

Internal portals & workflow tools

Quoting, scheduling, onboarding, approvals — the processes that live in email threads and shared documents until somebody builds them properly.

Integrations between systems

Two tools that both hold half the truth, connected — so nobody is retyping the same data into a second system and introducing errors doing it.

Customer-facing web applications

Booking, accounts, calculators, configurators and portals — built on the same foundations as our websites, with the same attention to speed and accessibility.
