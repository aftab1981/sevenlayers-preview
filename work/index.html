02 · Infrastructure · Data centre
Custom softwareInfrastructure

Unified iDRAC Management — every server in one console.

A single console for a whole Dell PowerEdge estate managed through iDRAC. Rather than opening one out-of-band interface per server, it consolidates every host into one view: fleet health, full hardware inventory down to the DIMM slot and drive bay, configuration drift, active faults, and reports you can hand to procurement or an auditor.

  • Every iDRAC host in one console, across multiple sites and environments
  • Fleet health scoring that weights status, firmware drift and drive telemetry
  • Full hardware inventory: CPU, memory, disks, RAID, NICs, PSUs, fans, transceivers
  • Faults, wear and BIOS drift surfaced automatically, ranked by severity

03 · E-commerce · Storefront design · Live 2026
Ecommerce designBrand & UIAdaptable

ZEVAR — a jewellery store designed around how jewellery is actually bought.

Most jewellery goes online through a template that treats a hand-set kundan piece like a phone case. We designed the opposite: a storefront where photography is the interface, browsing works by occasion as well as by piece, bridal sells as a matched set rather than four products, and the checkout is built around Cash on Delivery and WhatsApp — because that is how the market it was drawn for actually pays. Bilingual wordmark, in Latin and Urdu. Designed end to end, and live.

  • Photography-led product pages — the piece is the interface, not a thumbnail
  • Browsing by occasion as well as by piece — everyday, party, wedding
  • Bridal merchandised as one matched set, opened by a WhatsApp styling call
  • Materials stated plainly — plating, zircon, faux pearl, skin-friendly base
  • Cash on Delivery and rupee pricing designed in, not bolted on

The design is a pattern rather than a one-off, so rebuilding it around another jewellery brand costs a fraction of designing one from scratch. The case study walks through all nine screens — fold, occasion browsing, catalogue, filters, the box, bridal and the phone layout — with the reason for each decision.

04 · E-commerce platform · Live 2026
Custom softwareE-commerceHeadless CMS

BookCart — new, used and PDF books in one basket.

A 5,475-title bookshop built on Next.js 15 with Payload CMS embedded in the same application — one deploy, one thing to secure, and a WordPress-like admin for the person merchandising it. It was built rather than bought because the catalogue does not fit a template: a used copy needs a condition grade, a PDF needs a file and no stock, and all three have to share a basket.

  • 5,475 titles, faceted by condition, format, genre and reading age
  • New, second-hand and DRM-free PDF modelled as one catalogue
  • Customer accounts, basket and checkout — verified in production
  • SEO built in from the first commit: sitemap, JSON-LD, redirects, per-page meta
  • Vercel + Neon Postgres + Cloudflare R2, deploying from main

Payments are the next piece of work — orders reach pending-payment and stop there, and the case study says so rather than implying a working till.

05 · Cyber Security · Microsoft 365
Custom softwareCyber securityLocal AI

Teams Link Monitor — every link shared in Teams, checked and explained.

A security dashboard for Microsoft Teams. It reads every link shared in chats and channels, checks each one against two independent threat-intelligence feeds, flags phishing language in the message text itself, and surfaces when the same malicious link is spreading across several people. It grew from a link scanner into a small SOC platform: case triage, audit logging, SIEM export and campaign detection — with three AI features that run entirely on a local model, so no message content ever leaves the machine.

  • Dual-engine URL reputation — VirusTotal and URLhaus, cross-checked against each other
  • Campaign detection: the same bad link shared by several people surfaces as one incident
  • Phishing-language detection on message text, so a message with no link at all still gets caught
  • Case management — triage status, assignment and a running analyst-note log per URL
