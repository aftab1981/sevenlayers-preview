Identity

One mark, seven bars.

Seven descending bars, each one shorter than the last — the seven layers of a stack, read top to bottom. It is the whole identity: there is no second mark, no seasonal variant and no illustration library standing in for one. Everything below is the same geometry in a different treatment.

This page exists so the mark stays the mark. If you are putting Seven Layers on an invoice, a slide, a shirt or someone else's site, take the files from here rather than lifting a screenshot.

The mark

Four grounds, one shape.

The mark is drawn as vector geometry that inherits its colour from whatever it sits on, so a single asset covers the light theme, the dark theme and every palette the site ships with. Pick by ground, not by file.

Using it

Clear space and minimum size.

Clear space

Keep clear space equal to the height of one bar on every side. The mark already carries that padding inside its own viewBox, so an SVG placed flush is correct — the dashed line shows where the boundary falls.

16px
24px
40px
64px

Minimum size

16px for the mark alone, 24px inside a lockup. Below 16px the gap between the bottom two bars closes up and the shape reads as a solid wedge rather than seven layers.

Do

Scale the lockup as one unit. Use the reversed mark on dark grounds. Take the files from this page.

Do

Use the single-colour mark wherever the gradient will not survive — one-colour print, embroidery, a fax, a favicon at 16px.

Don't

Recolour the bars individually, rotate or mirror the mark, add a stroke or shadow, or stretch it to a non-square box.

Don't

Set the name in a different typeface, place the mark on a busy photograph, or rebuild it by eye — the geometry is exact.
