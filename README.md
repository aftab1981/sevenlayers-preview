# Seven Layers — static preview

Generated output. Nothing here is written by hand and every file is
overwritten on each build, so there is nothing to edit or contribute.

It is a static build of the Seven Layers website, published here so it
can be viewed without the production host. The live site is
<https://www.sevenlayers.online>.

The forms, the chat widget, the domain search and the admin area all
need a server and are inactive in this build — a bar at the top of
every page says so. Every page is served `noindex`: this is a copy for
looking at, not a second site.
